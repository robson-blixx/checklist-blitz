# Checklist Blitz

Painel de acompanhamento de checklists Jet e Total, publicado no GitHub Pages. O mesmo motorista pode ter um cadastro em cada operação. O vencimento é calculado a partir da emissão: 20 dias para Jet e 15 dias para Total.

O responsável escolhe quantos dias antes do vencimento aparece o aviso (padrão: 5 dias). O status muda automaticamente para **Aviso pendente**, **Vence hoje** ou **Vencido** conforme a data de São Paulo. Após avisar o motorista por conta própria, pode marcar **Solicitado**. Uma nova emissão inicia outro ciclo.

Há um aviso sonoro curto quando a página é aberta e existem checklists que precisam de atenção. Por regras dos navegadores, pode ser necessário clicar em **Ativar som dos avisos** uma vez. O aviso toca uma vez por dia e também quando surgem novas pendências na página aberta.

Não há envio automático de WhatsApp nem hospedagem Python. Os cadastros ficam guardados somente no navegador e dispositivo usados; limpar os dados do navegador pode apagá-los. O GitHub Pages hospeda apenas a página.
